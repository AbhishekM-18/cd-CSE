# 👉cd-CSE 
##  Your Command To Navigate The World Of Computer Science.
#### `cd-CSE` 🧭

> **A practical roadmap for navigating Computer Science.**

If you're studying Computer Science, you've probably asked yourself this at some point:

**"What am I actually supposed to learn?"**

C, C++, Python.
DSA.
Competitive programming.
Web development.
App development.
AI/ML.
Cloud.
Open source.
Hackathons.
Internships.

There is no shortage of things to learn. The difficult part is figuring out **where they fit, what they are actually useful for, and what you should focus on next.**

That's what `cd-CSE` is about.

---

## 🧭 What is `cd-CSE`?

`cd-cse` is an open collection of roadmaps, resources, notes, and perspectives designed to help Computer Science students navigate the field.

The name comes from the terminal command:

```bash
cd CSE
```

**Change directory → enter Computer Science.**

But unlike a traditional roadmap, this isn't meant to tell everyone to follow exactly the same path.

Computer Science has many paths.
The goal is to help you understand them well enough to choose your own.

---

## 🗺️ What's inside?

### 💻 Programming

Understand programming fundamentals before worrying about frameworks and trends.

### 🧠 Data Structures & Algorithms

Learn how to approach problems, analyse solutions, and build strong fundamentals.

### ⚡ Competitive Programming

Understand what competitive programming is, what it teaches, and where it fits.

### 🛠️ Development

Explore web, mobile, backend, and other areas where you can turn ideas into working software.

### 🤖 AI & Machine Learning

Understand the field without feeling like you need to learn every new AI tool that appears.

### 🌐 Open Source

Learn how real software is built collaboratively and how you can start contributing.

### 🚀 Projects & Hackathons

Move from consuming tutorials to actually building things.

### 📚 Resources

A collection of useful learning resources, tools, and references.
