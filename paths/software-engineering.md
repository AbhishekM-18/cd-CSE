# 💻 Software Engineering

Software Engineering is the process of designing, building, testing, deploying, and maintaining software systems.

It is much broader than simply writing code.

A software engineer may build websites, APIs, mobile applications, backend systems, developer tools, distributed services, or large-scale software platforms.

---

## 🧭 The Software Engineering Landscape

```text
Software Engineering
│
├── Frontend Development
├── Backend Development
├── Full Stack Development
├── Mobile Development
└── Systems Software
```

These areas overlap heavily.

```text
Frontend
   ↕
Backend
   ↕
Database
   ↕
Cloud / Infrastructure
   ↕
Systems
```

# 🎨 Frontend Development

Frontend development focuses on the part of an application users directly interact with.

### What Does a Frontend Developer Do?

- Build user interfaces
- Implement designs
- Connect applications to APIs
- Manage application state
- Handle user interactions
- Improve accessibility
- Optimize performance
- Test interfaces
- Fix browser-specific problems

### Learn

- HTML
- CSS
- JavaScript
- TypeScript
- Responsive design
- Accessibility
- Browser fundamentals
- HTTP basics
- APIs
- State management

### Common Technologies

- React
- Next.js
- Vue
- Angular
- Tailwind CSS

You do not need to learn every framework.

Start with the fundamentals first.

# 🧠 System Design

As applications become larger, architecture becomes important.

Learn:

- Scalability
- Availability
- Reliability
- Load balancing
- Caching
- Databases
- Queues
- Microservices
- Distributed systems

Start with simple architectures.

```text
Client
  ↓
Application
  ↓
Database
```

Then gradually explore:

```text
Clients
   ↓
Load Balancer
   ↓
Application Servers
   ↓
Cache
   ↓
Database
   ↓
Message Queue
   ↓
Workers
```

Do not jump into microservices before understanding a well-designed monolith.

# 🧠 How to Think Like a Software Engineer

Don't only ask:

> "How do I write this code?"

Also ask:

- What problem am I solving?
- What are the requirements?
- What could go wrong?
- How will this scale?
- How will I test it?
- How will I debug it?
- How will another developer understand it?
- How will users interact with it?
- How will I deploy it?
- How will I maintain it?

Software engineering is about the entire lifecycle of software.

### If you enjoy logic, APIs, and databases

Explore:

→ Backend

### If you want to understand the complete application

Explore:

→ Full Stack

Explore:

→ Mobile
