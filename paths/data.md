# 📊 Data

Data is one of the largest areas within Computer Science.

It focuses on collecting, storing, processing, analyzing, and using data to understand problems and make better decisions.

The field connects:

- Data Analysis
- Data Engineering
- Data Science
- Statistics
- Databases
- Machine Learning
- Business Intelligence
- Data Platforms

---

## 🧭 The Data Landscape

```text
Data
│
├── Data Analytics
│   └── Data Analyst
│
├── Data Engineering
│   └── Data Engineer
│
├── Data Science
│   └── Data Scientist
│
├── Business Intelligence
│   └── BI Analyst / BI Developer
│
└── Advanced Data Systems
    ├── Big Data
    ├── Data Platforms
    └── Machine Learning Data
```

These areas overlap.

```text
Data Sources
     ↓
Data Engineering
     ↓
Data Storage
     ↓
Data Processing
     ↓
Data Analysis
     ↓
Insights / Models
     ↓
Decisions / Applications
```

# 🧠 How to Think Like a Data Professional

Don't immediately ask:

> "Which model should I use?"

First ask:

- What is the actual problem?
- What data do I have?
- Where did the data come from?
- Is the data reliable?
- What does each field mean?
- What is missing?
- What could introduce bias?
- What does success mean?
- Who will use the result?

Good data work begins with understanding the problem.
