# 📊 Data

Data is a broad area of Computer Science focused on collecting, storing, processing, analysing, and using data to answer questions or build systems.

It includes several different roles, and they overlap with software engineering, databases, statistics, cloud, and AI.

---

```text
Data

│
├── Data Engineer
│
└── Data Scientist
```

## 🎯 How to Explore Data

Don't start by trying to learn every data technology.

Try this:
```text

Pick a dataset
     ↓
Ask a question
     ↓
Clean the data
     ↓
Analyse it
     ↓
Visualize the results
     ↓
Explain what you found
```

Then try different types of work.

If you enjoy analysing and communicating findings, explore Data Analytics.

If you enjoy building pipelines and systems, explore Data Engineering.

If you enjoy statistics, experimentation, and modelling, explore Data Science.

These are exploration signals, not strict rules.
